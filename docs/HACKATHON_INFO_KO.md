## 2. 트랙과 주제

### 트랙 (둘 중 하나)
| 트랙 | 대상 | 심사 초점 |
|---|---|---|
| **Indie Developer** | 개인 개발자, 학생 | **창의성, 기술적 야심, 실제로 돌아가는지** |
| Startup | 실제 제품을 만드는 팀·창업자 | 기술적 완성도, 실제 운영 환경에서 버티는지 |

### 주제 (두 트랙 모두 둘 중 하나)
- **Build for Your World**: Meta 모델을 내 분야로 가져와, 직접 겪어 본 문제를 풀고, 시간과 머리 쓸 일을 덜어 주고, 전에 못 하던 일을 가능하게 만든다.
- **Push the Frontier**: 소프트웨어, 로봇, 제조, 에너지, 소재 등의 어려운 문제에 Meta 모델로 도전한다. 모델이 현실 세계를 만나면 무엇이 가능해지는지 보여 준다.

## 4. 규칙

### 기본 규칙 (개막 슬라이드 "Build it new, build it in the open")
- **새 작업만**: 10-26 ~ 11-04 사이에 만든 것만 인정. 스타트업은 기존 제품을 가져와도 되지만 대회 기간 작업만 인정.
  - Discord 운영진 답변(10-26): 개인 트랙도 기존 코드를 기반으로 쓸 수는 있으나, **대회 기간에 만든 것을 분명히 구분해 보여야** 함.
- **팀은 최대 4명**, 혼자 참가 가능. 팀원 전원이 선발된 사람이어야 함.
- **GitHub 저장소는 공개(public)**여야 함.
- **직접 만든 것만 시연**: 대회 중 무엇을 만들었는지 심사위원이 알아볼 수 없으면 실격.
- **금지**: 법, 윤리, 플랫폼 정책 위반. **권리가 없는 코드, 데이터, 자산 사용**은 실격.
- 중복 신청, 거짓 신원 정보, 스팸은 실격.
- 오픈소스 라이브러리 사용은 가능(운영진 Ivan 답변).

### 피해야 할 흔한 프로젝트 (개막 슬라이드 "Skip these overdone projects", 전체 목록 아님)
- AI 의료 조언 (정신건강 상담, 피부 잡티 감지 포함)
- 기본 RAG 앱
- 단순 이미지 분석기
- **Streamlit 앱**
- **대시보드가 핵심 기능인 것**
- "교육용 AI" 챗봇
- AI 채용 지원서 심사기
- AI 영양 코치
- 성격 분석기
- 스포츠 분석기나 코치
- (참가 안내) 정치·전쟁 관련

## 9. Meta AI 제품 (dev.meta.ai/docs/models 기준)

### Meta Model API로 쓰는 모델
| 모델 ID | 입력 → 출력 | 특징 |
|---|---|---|
| `muse-spark-1.3` (1.2, 1.1도 있음) | 글·그림·영상·음성·PDF → 글 | "에이전트·코딩 작업용". 양이 많거나 빠른 응답, 비용이 중요한 작업용. **새 작업에 권장**. 컨텍스트 1,048,576 토큰. 생각 깊이 max까지. 1.3의 음성 이해는 완전 지원 아님. Contributor mode(보낸 내용이 학습에 쓰일 수 있는 대신 할인) |
| `muse-wonder-1.0` | 같음 | "가장 강력한 모델". 오래 걸리는 복잡한 작업, 비용보다 성능이 중요할 때. **preview**. 병렬 도구 호출 |
| `muse-image-1.0` | 글·그림 → 그림 | 생성과 편집 |
| `muse-voice-transcribe-1.0` | 음성 → 글 | 25개 언어 받아쓰기. **음성 합성(TTS)은 없음** |
| `sam-3.1` | 글 지시·그림·영상 → 상자·마스크 | 물체 찾기와 분할 |

### 공개 가중치 모델 (Model API에서는 안 됨, 직접 또는 파트너에서 실행)
| 모델 | 크기 | 필요 사양(문서) |
|---|---|---|
| Muse Spark Open | 816B MoE (실제 계산 42B) | Blackwell GPU 4장(NVFP4) / 8장(BF16). SGLang, vLLM, TensorRT-LLM, llama.cpp |
| Muse Glimmer | `Muse-Glimmer-30B` (이름 기준 약 30B) | Spark에서 증류. 글·그림 → 글. B300 1장(BF16), Intel Arc 32GB×2에서 검증. 디스크 약 80GB. vLLM, SGLang, llama.cpp, ExecuTorch |

### Muse Code (코딩 에이전트)
- "터미널과 CI용 Meta 코딩 에이전트". `muse`(대화 화면), `muse exec "할 일"`(한 번 실행).
- 로그인: API 키(`META_API_KEY` 또는 `muse auth set --api-key-stdin`) 또는 브라우저 로그인. API 사용은 토큰만큼 청구. 월 정액 구독은 별도 선택 사항.
- 구독하면 Muse Wonder Full 사용 가능.
- VS Code 확장은 문서에 없음(터미널 방식).
- Windows 설치: `irm https://dev.meta.ai/install.ps1 | iex`
