## What is built

  Kokoro adapter ready, ≤2 attempts/cut, real durations) into the
  Voice PC.

  license allowlist, ≤6 images, checked tables/formulas).

  (≤3 renders, layout-only log).
- `video_production` code node: joins slides + voice into the
  `video` record, `captions.srt` (Wren's exact text, proportional
  timing), `storyboard_table.json`, and `assembly.json` with the
  ffmpeg command. The flow never renders the MP4 itself.
- Flow file v8: 20 nodes (12 crew + code + 6 PCs + final),
  37 solid + 44 dotted lines, final takes only `video` +
  `storyboard_table`.
- Step mode: run one node, show report (KO summary first) +
  INPUTS + cost, Approve / Re-run with note / Stop; re-run
  invalidates later stages. New Flow-tab STEP MODE panel and
  server endpoints (`step`, `approve`, `invalidate`, `status`,
  `file`).
- Three new PCs (Image, Generated, Voice) on the PC tab with
  entries, files, and recipients; Flow tab renders the code node.

Phase B tool layer (code complete, fixtures only — first live

## Choices I made

- Wren's two design ports merge into one `narration` v2 line
  (times embedded per cut) — one less line class to validate.
- Helper personas are self-stubbing ("none" when a tool is
  ungranted), so Phase B needs no persona rewrites.
- The code node degrades honestly: no turns → proportional
  subs + `speech.unavailable` in `assembly.json`, never silent.
- Vision attaches staged raster only; SVG is named, not sent
  (vision needs Remotion PNG in live runs).
- Live image/speech API shapes follow the OpenAI-compatible
  convention of our endpoints, marked "first live call
  verifies" in code.
- Remy reuses the female-e Mini variant with a distinct tint:
  only 12 variants exist and Iris (not in the v8 flow) holds it.
- PAGE_BUILD stamp not bumped: the ancestry check passes and
  the previous served-code commit did the same.

## How to do the first run in step mode

1. Run `start_server.bat`, open `http://localhost:8000/`
   in a browser, press Ctrl+F5, open the Flow tab.
2. In the Order tab, finish one order (5 answers + PDF +
   Yes confirm) and note its id (`ord-…`).
3. Flow tab: enter the order id, set STEP MODE target to
   `sales_sam`, press RUN STEP. Wait for `step_paused`.
4. Pick a stage + file (report.md first — it starts with the
   Korean summary), press VIEW FILE. Read the COST column.
5. Set target to the finished stage, press APPROVE. Set the
   next target, press RUN STEP. Repeat to `video_production`,
   then target `final` and RUN STEP once more.
6. To redo a stage: select it, optionally write a note,
   press RE-RUN (later stages are invalidated and re-run).
7. Outputs live in `runs/<run_id>/video_production/`:
   `assembly.json` (ffmpeg command + speech note),
   `captions.srt`, `storyboard_table.json`. Render the MP4
   by running the recorded ffmpeg command yourself.
