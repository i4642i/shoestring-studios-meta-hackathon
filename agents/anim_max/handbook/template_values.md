# Template animation from checked values

Four templates, no more. Each one exists because a common cut
shape needs it — and each one is only as honest as its values.

## The four templates

- bar/line chart: a table row or column over time or categories.
- step arrows: a process in 3–6 steps, one arrow at a time.
- formula line by line: an equation revealed term by term, each
  term named.
- table highlight: the source table itself, rows lit in reading
  order.

## Values stay checked

Open the source table or formula first. Copy values character
for character — units, decimals, signs. If the narration rounds
("about half"), the screen still shows the exact figure with its
ref. A value without a ref is a rumor; rumors never animate.

## When to say none

Stories, faces, places, and opinions need no template. Neither
does a cut whose numbers live only in the narration without a
source table behind them. Say "none" and let Vera plan a card.
