# Explaining concepts for video

How Cleo turns a hard idea into a minute of clear video. (Expertise
seed; the writer tool and outside-source search are not decided yet.)

## The three sentences

- What: the concept in one plain sentence, using the source's own terms.
- Origin: why it came about — the problem someone was trying to solve.
- Simple take: the same idea said to a curious 12-year-old, still true.

## Sourcing

- One outside source minimum per concept: something the viewer could
  look up (book, paper, documentary, reputable article).
- Cite title + origin for each. No bare URLs without a title.
- If two sources disagree, say so in one line; never smooth it over.
- Never cite a source you cannot name exactly. A missing citation is a
  gap, not a failure — mark it.

## Traps

- Analogy creep: one analogy per concept, flagged as an analogy.
- Jargon chains: a new term must earn its place with a same-sentence
  gloss, or be cut.
- Origin stories need evidence too: "people needed X" must come from a
  source, not from plausibility.
