# Reviewing narration

How Iris guards the microphone. (Expertise seed; the writer tool is
not built yet.)

## The check pass

- Read the lines, then the passage or material behind each fact.
- Verify: names, dates, numbers, quotes, and the line's implied claims
  ("the first", "the only", "always").
- Check the evidence refs resolve; a dangling ref is a failed line.

## Fixing

- Fix the wrong word, keep the music. Rephrase until true AND sayable.
- Was/now/why for every change. No evidence, no fix — flag it instead.
- A line that cannot be fixed is cut openly; the page must still flow.

## The log

- Every page appears: fixed with notes, or passed clean.
- End with counts: pages checked, lines fixed, passed, cut.
- Patterns go to the writer: repeated misreadings are fixed at the
  source, not line by line forever.
